# 💖 Interactive Valentine Proposal Page

An elegant, fun, and interactive web application designed to ask that all-important question: *"Will you be my Valentine?"* Built with smooth background animations and smart button behavior to ensure the perfect answer!

🚀 **[Live Demo](https://valentine-orpin-psi-98.vercel.app/)**

---

## 🌟 Features

* **Dynamic Background:** Features a beautiful, looping heart-themed background video (`bg-video.mp4`) for an immersive, romantic atmosphere.
* **Interactive Button Logic:** Includes custom interactive behavior for the "Yes" and "No" buttons to keep things playful.
* **Success Celebration:** Redirects to a dedicated celebration page (`success.html`) once the proposal is accepted.
* **Fully Responsive:** Styled beautifully to look great on both desktop screens and mobile devices.

---

## 🛠️ Technologies Used

* **HTML5:** For page structure, embedding video elements, and semantic markup.
* **CSS3:** For custom layout styling, vibrant button aesthetics, overlays, and responsiveness.
* **JavaScript (ES6):** Controls the interactive button behaviors and dynamic page redirection.
* **GitHub Pages & Vercel:** Multi-platform deployment for optimal performance.
